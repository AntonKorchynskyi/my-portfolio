## Why

The current portfolio website lacks critical UX elements and content strategy that modern tech recruiters and hiring managers expect in 2026. While the technical foundation is solid, the site fails to effectively communicate value proposition, showcase work through case studies, and provide clear pathways for contact and resume access. This limits conversion opportunities and makes it harder for recruiters to quickly assess fit for roles. The portfolio needs to transform from a basic information display into a compelling narrative that demonstrates problem-solving, impact, and professional goals.

## What Changes

- **Hero Section Enhancement**: Strengthen value proposition with specific, outcome-focused messaging. Add prominent CTA buttons (Resume download, View Work, Contact). Replace photo placeholder with professional headshot. Fix placeholder social links.
- **Projects Transformation**: Convert basic project cards into detailed case studies with Problem → Process → Outcome structure. Add live demo links alongside GitHub repos. Remove placeholder projects. Add project-specific screenshots and tech stack badges.
- **About Me Section**: Create dedicated section (or expand Overview) with personal narrative, career goals, and what roles/projects are being sought. Humanize the profile while maintaining professionalism.
- **Resume Download**: Add prominent resume PDF download buttons in header and Overview section. Ensure easy access throughout the site.
- **Contact Form Enhancement**: Integrate contact form with backend service (Formspree, Netlify Forms, or EmailJS). Add success/error messaging. Provide alternative contact methods (direct email link, optional Calendly).
- **Skills Prioritization**: Reorder skills based on target roles. Add proficiency indicators or years of experience. Link skills to relevant projects.
- **Additional Sections**: Add footer with social links and resume download. Consider testimonials/social proof section. Add metrics dashboard (years of experience, projects delivered, certifications).
- **Content Updates**: Fix all placeholder URLs (GitHub, LinkedIn, email). Update email addresses throughout. Add career goals statement.
