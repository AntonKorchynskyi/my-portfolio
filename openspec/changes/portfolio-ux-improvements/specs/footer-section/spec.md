## ADDED Requirements

### Requirement: Site footer component
The portfolio SHALL include a footer component displayed at the bottom of the page.

#### Scenario: User scrolls to bottom
- **WHEN** a user scrolls to the bottom of the portfolio page
- **THEN** a footer section is displayed

### Requirement: Footer social links
The footer SHALL include links to social media profiles (GitHub, LinkedIn, etc.).

#### Scenario: User clicks footer social link
- **WHEN** a user clicks a social link in the footer
- **THEN** the corresponding social media profile opens in a new tab

### Requirement: Footer resume download
The footer SHALL include a link to download the resume PDF.

#### Scenario: User clicks footer resume link
- **WHEN** a user clicks the resume link in the footer
- **THEN** the resume PDF downloads

### Requirement: Footer copyright notice
The footer SHALL include a copyright notice with the current year and developer name.

#### Scenario: User views footer
- **WHEN** a user views the footer
- **THEN** a copyright notice is displayed (e.g., "© 2026 Anton Korchynskyi")

### Requirement: Footer tech stack attribution
The footer SHALL include attribution showing the technologies used to build the portfolio (e.g., "Built with React & TypeScript").

#### Scenario: User views footer
- **WHEN** a user views the footer
- **THEN** tech stack attribution is visible (e.g., "Built with React & TypeScript")
