## ADDED Requirements

### Requirement: Skills reordering by target roles
The skills section SHALL display skills in an order that prioritizes skills relevant to the developer's target roles.

#### Scenario: Recruiter views skills section
- **WHEN** a recruiter views the skills section
- **THEN** skills are ordered with the most relevant skills for target roles appearing first (e.g., Frontend skills first if targeting React roles)

### Requirement: Proficiency indicators
The skills section SHALL include visual or textual indicators showing proficiency level or years of experience for each skill category.

#### Scenario: User views skills section
- **WHEN** a user views the skills section
- **THEN** proficiency indicators are visible (e.g., "Expert/Intermediate/Beginner" or "5+ years")

### Requirement: Skills linked to projects
Skills SHALL be linked to relevant projects where possible, allowing users to see skills in action.

#### Scenario: User wants to see skill in action
- **WHEN** a user views a skill category
- **THEN** links or references to relevant projects using that skill are available (if applicable)

### Requirement: Soft skills inclusion
The skills section SHALL include soft skills or delivery-related skills (e.g., "Cross-team collaboration", "Technical documentation", "Agile/Scrum").

#### Scenario: User views skills section
- **WHEN** a user views the skills section
- **THEN** soft skills or delivery skills are included alongside technical skills
