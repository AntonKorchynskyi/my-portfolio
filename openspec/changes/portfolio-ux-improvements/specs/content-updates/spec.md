## ADDED Requirements

### Requirement: All placeholder URLs replaced
All placeholder URLs (GitHub, LinkedIn, email) throughout the portfolio SHALL be replaced with real, functional URLs.

#### Scenario: User clicks any social or external link
- **WHEN** a user clicks any social media link, GitHub link, or external link
- **THEN** the link points to a real URL, not a placeholder (e.g., not "https://github.com/example")

### Requirement: All placeholder emails replaced
All placeholder email addresses (e.g., "anton@example.com") SHALL be replaced with the developer's real email address.

#### Scenario: User views email address
- **WHEN** a user views any email address in the portfolio
- **THEN** a real email address is displayed, not a placeholder

### Requirement: Production-ready content
All content throughout the portfolio SHALL be production-ready, with no placeholder text, "TBD" values, or incomplete information.

#### Scenario: User views any section
- **WHEN** a user views any section of the portfolio
- **THEN** all content is complete and production-ready (no placeholders, "TBD", or incomplete information)

### Requirement: Career goals statement added
The portfolio SHALL include a clear statement about what roles or projects the developer is seeking, visible in appropriate sections (Hero or About Me).

#### Scenario: Recruiter views portfolio
- **WHEN** a recruiter views the portfolio
- **THEN** a career goals statement is visible indicating what opportunities the developer is seeking
